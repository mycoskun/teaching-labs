# Course labs

Interactive simulations and files for my courses at Karadeniz Technical University,
Department of Mechanical Engineering. Every page runs in the browser (phone or laptop);
nothing needs to be installed.

**Open the labs:** https://mycoskun.github.io/teaching-labs/

## Contents

| Course | Material | Link |
|---|---|---|
| ME 3001 System Dynamics and Control | Lecture 1 · Feedback lab: cruise control, shower delay, Watt's governor, "you are the controller" | [open](https://mycoskun.github.io/teaching-labs/me3001/l01-feedback-lab/) |
| ME 3001 System Dynamics and Control | Lecture 3 · Model lab: pendulum linearization, across and through variables, machine and circuit twins, impedance trainer | [open](https://mycoskun.github.io/teaching-labs/me3001/l03-model-lab/) |
| ME 3001 System Dynamics and Control | Lecture 4 · One Block: block diagram reduction game with 40 levels, random practice (two inputs, numeric blocks), a which-rule quiz and class voting; Turkish and English | [open](https://mycoskun.github.io/teaching-labs/me3001/l04-one-block/) |
| ME 3001 System Dynamics and Control | Lecture 5 · System lab: DC servo motor, quarter-car suspension, four transfer-function types, natural frequency and damping ratio, two disks on a shaft, six games; Turkish and English | [open](https://mycoskun.github.io/teaching-labs/me3001/l05-system-lab/) |

## Layout

```
index.html                  landing page with the list of labs
<course>/<lecture>-<name>/  one folder per lab or file set, entry page index.html
```

Each simulation states its model equations, parameters and sources in its
"Model and numbers" section. The models are teaching models, simplified on purpose.
