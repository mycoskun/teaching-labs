# Course labs

Interactive simulations and files for my courses at Karadeniz Technical University,
Department of Mechanical Engineering. Every page runs in the browser (phone or laptop);
nothing needs to be installed.

**Open the labs:** https://mycoskun.github.io/teaching-labs/

## Contents

| Course | Material | Link |
|---|---|---|
| ME 3001 System Dynamics and Control | Lecture 1 · Feedback lab: cruise control, shower delay, Watt's governor, "you are the controller" | [open](https://mycoskun.github.io/teaching-labs/me3001/l01-feedback-lab/) |

## Layout

```
index.html                  landing page with the list of labs
<course>/<lecture>-<name>/  one folder per lab or file set, entry page index.html
```

Each simulation states its model equations, parameters and sources in its
"Model and numbers" section. The models are teaching models, simplified on purpose.
